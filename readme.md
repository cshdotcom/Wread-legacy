# Wread-legacy

> 🚨 **本项目为历史存档，不再继续开发维护！**
> 👉 持续迭代新版本：**[Readest-Lite](https://github.com/cshdotcom/readest-lite)**
> 💬 社区交流论坛：**[NodeByte 社区论坛](https://nodebyte.cn/forums)**

Wread 是轻量化自托管Web电子书阅读器，也是 **Readest-Lite 的前身项目**。
原生支持 EPUB、PDF 等主流电子书格式，内置在线书籍下载、书库管理、阅读标注、TTS文本朗读等功能，所有书籍文件存储于你自己的服务器，保护阅读隐私，无需依赖第三方云服务。

本仓库仅用于留存历史源码，不会新增功能、不再合并PR。
推荐所有用户迁移至重构升级后的 Readest-Lite。

## ✨ Readest-Lite 升级亮点
Readest-Lite 在 Wread 的基础上重构整体架构，优化Docker一键部署体验，新增AI阅读辅助、知识库对接、批量书籍管理等能力，持续迭代开发。

## 功能清单（Wread 历史版本）
- 电子书格式：EPUB、PDF
- 自托管部署，本地存储书籍
- 在线网页电子书抓取入库
- 完整书库管理、分类管理
- 阅读高亮、笔记、标注导出
- TTS 文本朗读
